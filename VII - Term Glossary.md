# VII - Term Glossary

This is the public glossary hub for the Pleroma Archive. It gathers the A-Z Dominion glossary pages into one reader-facing doorway so new readers do not have to search the folder tree by hand.

## How To Use This Glossary

Use the glossary when a note introduces a term before explaining it. Start with the [[Dominion_Glossary_Rail_v1|Glossary Rail]] for the smallest orientation path, then open the A-Z pages when you need a wider term list.

The glossary is a navigation aid, not a final canon dictionary. Several letter pages contain placeholder definitions that still need editorial review. The hub itself is CANON because it is the current authoritative route into the glossary layer.
