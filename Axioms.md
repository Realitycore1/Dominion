# MOT — Axioms & Root Structures

## Axiom Types (overview)
- **Causal:** define cause‑and‑effect (deterministic vs post‑selected).  
- **Contradiction:** allow/forbid inconsistency.  
- **Continuity:** govern identity persistence across time change.  
- **Consciousness:** conditions for awareness to emerge.  
- **Observation:** effect of being seen/remembered.  
- **Emergence:** whether complexity increases or stagnates.  
- **Self‑Reference:** recursion and simulation allowances.

## Alternate Root Structures (catalog)
- **Primis Root:** causal, identity‑conserved, recursive — Dominion standard; stable and logic‑bound.  
- **Ultis Root:** anti‑causal, contradiction‑permissive — entropy/madness zones.  
- **Chorus Root:** observational, non‑hierarchical, consciousness‑prior — belief/observer‑anchored realities.  
- **[[Eminentem]] Root:** self‑referential, discrete, recursive — nested simulations and loops.  
- **Fractaline Root:** contradiction‑allowed with causal drift — unstable partial realities, corruption‑prone.

## Compatibility Hints (examples)
- **Dominion:** Primis; supports technomagic with audits and anchors.  
- **Dark Eternities:** Ultis; entropic lords, verse breakers.  
- **Silent Chorus / Harmonics:** Chorus‑aligned.  
- **Ancestor‑Minds & sims:** Eminentem; where simulation‑collapse risks live.  
- **Broken Verses / Fragmented gods:** Fractaline borders.

> Use this module to choose root/axiom profiles when defining a verse or diagnosing drift.

# MOT-EXP-TH-08 — Axiomatic Collision Dynamics

## Overview
Axiomatic collisions occur when two verse-structures founded on differing roots interact. Outcomes range from benign merges to catastrophic paradox basins. This note summarizes the collision taxonomy, mechanics, consequences, and Dominion countermeasures.

## Collision Types (taxonomy)
- **Homogeneous:** shared root → coherent merge/fusion; lowest risk.  
- **Semi‑Compatible:** overlapping axiom sets → memory bleed, partial logic rewriting.  
- **Incompatible:** mutually exclusive roots → collapse zones, causality warps.  
- **Paradoxical:** contradiction-based roots vs deterministic structures → loops, memory splinters, null events.  
- **Trans‑Axiomatic:** contact with roots beyond the catalog (e.g., Dark Eternity) → unpredictable, often irreversible.

## Core Mechanics
- **Axiom Imposition:** the stronger root attempts to overwrite weaker logic states.  
- **Boundary Fracture Zones:** irreconcilable regions collapse into null or paradox.  
- **Entity Incompatibility:** non‑conforming lifeforms may phase out, mutate, or cease.

## Narrative‑Scale Consequences
- **Verse Memory Bleed:** populations recall external events/people.  
- **Reverse Causality Leak:** outcomes precede causes; post‑selected effects appear.  
- **Collapse Conversion:** locales become semi‑real, partially erased, or paradox‑infested.  
- **Root Infection:** observer anomalies propagate through systems.  
- **Temporal Ruin:** time fractures and unresolved futures spread outward.

## Dominion Countermeasures
- **Axiomatic Stabilizers:** assert Primis logic locally.  
- **Aetheric Containment Vaults:** secure incompatible entities/zones.  
- **Collapse‑Through‑Rebirth Doctrine:** reset logic‑infected sectors under writ.  
- **Verse Quarantine Protocols:** seal contaminated verses with Confluencia lattices.

## Field Checklist (quick reference)
1. Detect **η spike + Δ𝒦** (aether/weather + sheath curvature).  
2. Classify **G/P/M** (Graze/Pierce/Merge).  
3. Quarantine with **Ζₑ↑** (impedance), deploy anchors.  
4. Run Reason Sheet; schedule **Bridge of Writ** if **ΔS** persists.  
5. Postmortem + PFN hashes; gradual reopen.
