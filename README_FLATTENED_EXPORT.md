# Flattened Dominion Vault Export

All vault files in this export have been placed in a single folder.

- Markdown notes have an **Original Vault Path** callout appended at the end.
- Duplicate filenames were disambiguated with a parent-folder label and short path hash.
- `.canvas` files were preserved as valid JSON and therefore were not given an appended Markdown path note. Their original paths are recorded in `FLATTENING_MANIFEST.csv`.
- macOS `__MACOSX` / `._*` metadata files were excluded.
- Text files were normalized to LF line endings.
