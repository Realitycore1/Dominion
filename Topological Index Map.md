How to navigate the Dominion Omniverse archive by scale

Purpose

This archive is organized by nested scale and containment.

The intended reading method is:

pick a large structure → open what exists inside it → zoom inward

You are not expected to read linearly.

⸻

I. Scale Ladder

Largest to Smallest
	1.	Megaverse / Basin Type
Major reality ecology (Forest, Ocean, Stone, etc.)
	2.	Multiverse
A contained collection of related Verses
	3.	Zone / Layer / Regional Domain
Major internal region or structural band within a multiverse
	4.	Verse
A full self-contained reality
	5.	Verse Interior Structure
The internal architecture of a Verse
(physics, species, cosmology, civilizations, anomalies, etc.)
	6.	Cosmic Structure
Superclusters, galaxies, systems, and worlds
	7.	Civilizational / Local Scale
States, factions, species, entities, events, objects, phenomena

⸻

II. How Zooming Works

Each level contains what exists inside it.

Example:

Forest Basin

contains:
	•	Eos Multiverse
	•	other forest-type multiverses

Eos Multiverse

contains:
	•	Dark Forest Zone
	•	Aphotic Zone
	•	Empyrean Continuum
	•	etc.

Totum Verse

contains:
	•	Totum
	•	Unreality
	•	Verse Composition
	•	and other internal structures

Totum

contains:
	•	physics
	•	species
	•	civilizations
	•	cosmic structures
	•	major phenomena

⸻

III. Example Descent Paths

Main Dominion Path

Forest Basin → Eos Multiverse → Dark Forest Zone → Totum Verse → Totum → Superclusters → Ho‘oleilana → Dominion

Metaphysical Path

Forest Basin → Eos Multiverse → Totum Verse → Unreality

Companion / Setting Path

Start Here → Beast Chronicles / Arcanum / Cosmologia

These paths are examples, not mandatory reading orders.

⸻

IV. Reading Modes

This vault supports multiple entry styles:

Atlas Mode

Zoom inward by scale and location

Codex Mode

Browse creatures, systems, and supernatural structure

Narrative Mode

Read dramatized stories and lived snapshots

Reference Mode

Use glossary, Q&A, and knowledge notes to recover context

⸻

V. Important Note

Not every note is a “place.”

Some entries are:
	•	structural explanations
	•	concept files
	•	historical records
	•	system references
	•	or lateral worldbuilding documents

If a file does not represent a location, it usually exists to explain the structure around it.
