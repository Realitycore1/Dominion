# Faction Atlas - Pleroma Archive

The Faction Atlas is the public route into civilizations, governments, factions, and major power blocs. It does not replace individual civilization files. It tells readers where to begin, what is ready to browse, and which folders are still draft scaffolds.

## Purpose Summary

This page exists because the civilization folder is large and uneven: some factions have strong overview material, some are mainly index scaffolds, and some root notes are still draft recovery pages. The atlas separates reader-ready routes from deeper development material.

## Reader Rule

Read factions in this order:

1. Start with [[World Orientation FAQ]] if the setting scale is unclear.
2. Use [[Civilizations Portal]] for the formal category route.
3. Use this atlas to choose a major power.
4. Open overview, timeline, government, doctrine, and military pages before specialized subfiles.

## Public Readiness Labels

| Label | Meaning |
| --- | --- |
| Reader-ready | The route can be used by a public reader now. |
| Strong draft | Substantial material exists, but it still carries DRAFT status or needs canon review. |
| Draft scaffold | The folder is useful for navigation, but several key notes are empty, brief, or imported. |
| Specialist route | Best read after the reader understands the broader civilization layer. |
