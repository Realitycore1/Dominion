# Alchemical Reagent Table (ART v1.0)
*Standardized Classification of Alchemical Inputs*

---

# I. Reagent Classification Framework

All alchemical reagents are categorized into three primary classes:

| Class | Description |
|------|-------------|
| **P-Class** | Physical substances (matter-based) |
| **E-Class** | Energetic manifestations (field-based) |
| **C-Class** | Conceptual constructs (information/intent-based) |

# V. Reagent Interaction Types

## Constructive Interaction
Reagents reinforce each other.

Example:
Gold + Lightning + Intent → High-efficiency energy conduit

---

## Stabilizing Interaction
Reagents control volatility.

Example:
Silver + Ice + Will → Stable containment crystal

---

## Destabilizing Interaction
Reagents induce transformation or chaos.

Example:
Toxin + Fire + Malice → Corrosive reactive compound

---

## Emergent Interaction
Creates entirely new properties.

Example:
Carbon + Memory + Lightning → Information-reactive crystal
