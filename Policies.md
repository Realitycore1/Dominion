The Eternity Program 
The Eternity program was initiated sometime after the first wave. It was tasked to devise an create a way to move a portion of the population to a new colony. The Eternity program became more feasible for scavenging the C.U ships and updating to current [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Galactic Federation/Military/Technology|Technology]], along with the new experimental Jump Drive.
