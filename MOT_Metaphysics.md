# MOT — Metaphysics (Ontology & Axioms)

**Aim.** Define the **ontic stack** of the [[Eos]] Overfold and the rules by which [[Axioms]] are imposed, drift, and are reimposed. Keep it compatible with the [[Physics]] pillars and [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Domain/Science/Technomagic|Technomagic]] governance.

## 1) The Ontic Stack (from deepest to lived)
1. **[[Primis]]** — pure axiom [[Domain]]; the minimal rule-sets that specify a [[Verse]] (notation: \(\mathcal{A}_v\)).  
[[Chapter XXIX (Verse Concursus)|Chapter XXIX (Verse Concursus)]]. **Sheath–Foam** — [[New Readers Start Here/I - Pleroma Archive/World/Locations/Oneiroverse Multiverse/Chorus of Archetypes/Boundary]] & bulk where physical fields live; couples to **[[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Domain/Science/Aether|Aether]] (Φ)** and **[[Verseon]] (Ψ)**.  
[[Chapter XXX (Munitum Age)|Chapter XXX (Munitum Age)]]. **Eosphoric ([[Aetheric]])** — the tunability layer; coherence (ℓᶜ), impedance (Ζₑ), noise (η).  
[[Chapter (The Old War)|Chapter (The Old War)]]. **Noetic** — minds, models, and information (entropy budgets, computation).  
5. **Liturgic** — [[Choirs]]/rites/consent keys (\(\mathcal{C},\,\kappa\)) that interface Noetic ↔ [[Aetheric]] ↔ Sheath.

> **Rule:** lower layers constrain upper; upper layers may **steer** lower only where chartered interfaces exist (e.g., sanctified windows, lawful rites).

## 2) Axiom Economy
- **Initialization:** a [[Verse]] is defined by \(\mathcal{A}_v\) (causality, conservation classes, locality bounds).  
- **Stability:** measured by \(S[\mathcal{A}_v]\) (resists drift).  
- **Drift:** slow change due to collisions, overload, or unauthorized rites.  
- **Reimposition:** application of **Reimposition Operators** \(\mathbb{R}\_i\): *[[Verse]] Anchor*, *Cruciform Mote*, *Bridge of Writ*—reset local [[law]] to spec.

**Failure smells** (metaphysical anomalies seen in the lab/story):  
- Mispriced causality (“luck pockets”), selective conservation loss, [[Ritual]] doubling (same rite “works twice”).

## 3) Sanctity & Unhallowing
- **Sanctification (RAC):** raise Φ, extend ℓᶜ, lower Ζₑ; binds rites exactly-once within scope and [[Time]] window.  
- **Unhallow/Damper (DVAA/ACA):** raise Ζₑ and/or η to blunt [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Domain/Science/Technomagic|Technomagic]] coupling; create Nulls (Veil Cages) where needed.

**Ethic ([[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Dominion/Dominion]] vs [[Domain]]):** [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Dominion/Dominion]] seeks **legible sanctity** (public audits); [[Domain]] uses **instrumental sanctity** (deniable, outcome-first).

## 4) Oaths, Proofs, and Rights
- **Oaths (liturgic contracts):** a rite that binds parties under Axiomatic Mechanics; requires **consent keys** on both ends.  
- **Reason Sheets (Athearn proofs):** formal models that predict outcomes **without** [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Domain/Science/Technomagic|Technomagic]]; required on shared corridors.  
- **[[Radiator Neutrality]] & Light-Hygiene:** liturgic norms with physical signatures (chartered exceptions in total war).

## 5) Tests & Diagnostics
- **Veil Cage Null Test:** if a device/rite behaves identically inside a verified Null, it is not [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Domain/Science/Technomagic|Technomagic]]-bound (or is counterfeit).  
- **Convergence Test:** iterate a rite; second invocation must fail if “exactly-once” clauses hold.  
- **Stability Audit:** monitor Φ, Ζₑ, η and \(S[\mathcal{A}_v]\); drift implies sabotage or nearby collisions.

## 6) Governance Hooks
- **RAC**: owns sanctification charters, choir licensing, and reimposition authority inside [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Dominion/Dominion]].  
- **DVAA/ACA**: deploy dampers, quietseeds, black-box ops in [[Domain]] jurisdictions.  
- **Harmonic**: posts safety standards (ports, clinics).  
- **Athearn**: veto-power via proof obligations on shared lanes.

## 7) Narrative Seeds
- A **false sanctum**: liturgy binds twice—revealing axiom rot and a hidden saboteur.  
- A **broken oath**: consent [[Key]] stolen; RAC invokes **Bridge of Writ** at great cost to reset a festival ground.  
- A **quiet war**: [[Domain]] dampers make a city “cold” (Ζₑ↑); [[Choirs]] fail silently; protests look like apathy.
