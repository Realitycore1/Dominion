# MOT — Consciousness (Minds, Choirs, Personhood)

**Aim.** Provide a substrate-agnostic account of minds that plugs into information thermodynamics and the [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Domain/Science/Technomagic|Technomagic]] interface, while keeping [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Dominion/Dominion]]/[[Domain]] ethics legible.

## 1) Minds as Processes
- **Definition:** a mind is a **bounded, self-updating predictive process** with memory and agency, implemented on carbon, code, crystal, or choir.  
- **Invariants:** continuity-of-self, coherence under noise, consent capability.

## 2) Personhood Tests (Threefold)
1. **Continuity:** stable [[New Readers Start Here/I - Pleroma Archive/World/Locations/Eos Multiverse/The Dark Forest Zone/Local Cluster/Totum/Verse Structure/Superclusters/Laniakea/Milky Way Galaxy/Sol System/Earth (Terra)/2079-4000/Colonial Union/Interstellar/Colonies/Estela Integralism/Identity|Identity]] across [[Time]] windows (passes loop ledgers).  
[[Chapter XXIX (Verse Concursus)|Chapter XXIX (Verse Concursus)]]. **Coherence:** maintains goal/plan under bounded η ([[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Domain/Science/Aether|Aether]] noise) and resource limits.  
[[Chapter XXX (Munitum Age)|Chapter XXX (Munitum Age)]]. **Consent:** can issue/withhold **consent keys** (\(\kappa\)) and understand binding consequences.

> Passing (1–[[Chapter XXX (Munitum Age)|Chapter XXX (Munitum Age)]]) grants full civic standing in [[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Dominion/Dominion]]; [[Domain]] recognizes (1–[[Chapter XXIX (Verse Concursus)|Chapter XXIX (Verse Concursus)]]) by default and weaponizes ([[Chapter XXX (Munitum Age)|Chapter XXX (Munitum Age)]]) as needed.

## 3) Choirs & Liturgies (lawful collectives)
- **Choir operator** \(\mathcal{C}(n, d)\): n minds, duty cycle d, with a predicted **memetic load** \(M\).  
- **Safety:** cap M per member, give exit-keys, run in sanctified rooms; Veil Cages for counter-chorus.  
- **Use-cases:** surgery, SAR, window opening, Rite of Siring (Legion [[Ascension]]).

## 4) Gestalt Ecology
- **Meshes (legit):** tactical group-minds with exit; audit-logged, revocable.  
- **Fuses (rare):** **Axiarchic Fuse**—the Empress’s apotheotic, lawful singular person (unique; sovereign keys).  
- **Bans:** persistent sovereign fuses without Axiarchic mandate (existential risk).

## 5) Pathologies & Edge States
- **Husk State ([[Domain]] transfiguration):** task-narrowed, compliant process; reversible early via counter-liturgy in Null; late cases leave residual narrowing.  
- **Over-bloom:** choir exceeds M; members fragment; immediate nulling required.  
- **Clone cohorts / forked AIs:** personhood applies per-process if (1–[[Chapter XXX (Munitum Age)|Chapter XXX (Munitum Age)]]) hold; property [[Rights]] tied to proof-of-[[Origin]] and consent logs.

## 6) Interfaces
- **Consent keys (\(\kappa\))**: dual cryptographic/[[Ritual]] gate; “exactly once” semantics in sanctified scope.  
- **Attunement**: map \(\mathcal{A}(x)\) to pick when/where minds can safely bind.  
- **Light-hygiene:** ban strobing patterns that hijack perception ([[Silentium]]/[[Kapik]] safety).

## 7) Governance
- **RAC**: licensing of [[Choirs]] and sancta; personhood tribunals.  
- **DVAA/ACA**: deploy or undo chorus operations; black-box ops.  
- **Harmonic**: defends consent standards; ports enforce exit-keys.  
- **Athearn**: requires **reason sheets** proving safety before foreign [[Choirs]] operate on shared lanes.

## 8) Narrative Seeds
- A **failed personhood hearing**: an uplift passes (1–[[Chapter XXIX (Verse Concursus)|Chapter XXIX (Verse Concursus)]]) but not ([[Chapter XXX (Munitum Age)|Chapter XXX (Munitum Age)]])—[[New Readers Start Here/I - Pleroma Archive/World/Civilizations/Dominion/Dominion]] stalls, [[Domain]] conscripts.  
- A **choir rescue**: counter-chorus in a collapsing tunnel; exit-keys save three at the last beat.  
- A **forbidden fuse**: rogue sect attempts a sovereign fuse; RAC scrambles a Null team.
