# Reading Order FAQ

This page helps readers choose a route through the archive without needing to understand the whole structure first.

## Is there one required reading order?

Answer:
No. The archive supports several routes. The safest public route is [[New Readers Start Here]] to [[Archive Index]] to [[Tiered Reader Path - Pleroma Archive]], then into the subject portal that matches the reader's interest.

Read next:
- [[Public Reader Path - Pleroma Archive]]

## Where should I start if I like characters?

Answer:
Start with [[Characters Portal]], then use [[Tier 1 - New Reader Portal]] for other easy entry points. Character pages are useful because they give readers names, relationships, and narrative anchors before the larger systems appear.

Read next:
- [[Characters Portal]]

## Where should I start if I like history or alternate timelines?

Answer:
Start with [[History Portal]], then read [[Timeline FAQ]]. For the Lithic Era specifically, use the whole timeline and world impact matrix before reading every dated note one by one.

Read next:
- [[History Portal]]
- [[Timeline FAQ]]
- [[Whole Timeline|Lithic Era Whole Timeline]]

## Where should I start if I like civilizations, governments, or military structures?

Answer:
Start with [[Tier 2 - Intermediate Portal]], then use [[Civilizations Portal]]. From there, move into the civilization, government, and military category indexes.

Read next:
- [[Tier 2 - Intermediate Portal]]
- [[Civilizations Portal]]

## Where should I start if I like megastructures, technology, or materials?

Answer:
Start with [[Tier 3 - Advanced Portal]], then use [[Megastructures Portal]], [[Technology Portal]], and [[Materials Portal]].

Read next:
- [[Tier 3 - Advanced Portal]]

## Where should I start if I like cosmology and metaphysics?

Answer:
Start with [[Advanced Cosmology FAQ Guide]], then read [[VI - Q&A/Part 1|Reader Q&A - Part I]]. After that, use [[Cosmology Portal]], [[Pleroma Portal]], and [[Master Omniversal Theory (MOT) Portal]].

Read next:
- [[Advanced Cosmology FAQ Guide]]

## What should I read if I only have a few minutes?

Answer:
Read [[New Reader FAQ]], open [[Archive Index]], and skim the four-tier table in [[Tiered Reader Path - Pleroma Archive]]. That gives the fastest understanding of how the archive expects readers to move.

Read next:
- [[New Reader FAQ]]

## How do I know when I am ready to move up a tier?

Answer:
Move from Tier 1 to Tier 2 when you recognize the main portals and can follow basic character, place, and timeline anchors. Move into Tier 3 when civilization and history context are clear. Move into Tier 4 when you are ready for cosmology, axioms, MOT, and Pleroma-level terminology.

Read next:
- [[Tiered Reader Path - Pleroma Archive]]

## What should I read before MOT?

Answer:
Read [[New Reader FAQ]], [[Advanced Cosmology FAQ Guide]], and [[VI - Q&A/Part 1|Reader Q&A - Part I]]. MOT is specialist material, so it is better approached after the reader understands Verse, Multiverse, Basin, Axiom, and Severance.

Read next:
- [[Advanced Cosmology FAQ Guide]]
