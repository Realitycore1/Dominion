In causal set theory (spacetime as a discrete partial order), a [[New Readers Start Here/I - Pleroma Archive/World/Locations/Oneiroverse Multiverse/Chorus of Archetypes/Boundary]] surface is a [[Locus]] where the order “thins” or ends: horizons, walls, cutoffs, or [[Verse]] interfaces. In the continuum limit they approximate timelike/spacelike/null boundaries.

Types (operational classes)
	•	Spacelike [[New Readers Start Here/I - Pleroma Archive/World/Locations/Oneiroverse Multiverse/Chorus of Archetypes/Boundary]] (Σ_s): ends a [[Time]] slice; looks like a thick antichain (many incomparable elements).
	•	Timelike [[New Readers Start Here/I - Pleroma Archive/World/Locations/Oneiroverse Multiverse/Chorus of Archetypes/Boundary]] (Σ_t): a worldtube wall; shows strings of near-maximal/minimal [[Chains]] hugging the edge.
	•	Null [[New Readers Start Here/I - Pleroma Archive/World/Locations/Oneiroverse Multiverse/Chorus of Archetypes/Boundary]] (𝓝): horizon-like; exhibits a characteristic link-rich but relation-poor sheet—many immediate relations (“links”) yet few longer [[Chains]] across it.
	•	Mixed / corner structures: junctions of the above; show hybrid signatures.

How to spot them in data (discrete diagnostics)

Let C be the causal set; deg⁺(x), deg⁻(x) future/past link degrees.
	•	Relation deficit index \Delta_R(x) = \hat{R}_{bulk}(x) - R(x): big positive values flag proximity to any [[New Readers Start Here/I - Pleroma Archive/World/Locations/Oneiroverse Multiverse/Chorus of Archetypes/Boundary]].
	•	Antichain thickness \Theta_A: count in a thickened antichain; high → spacelike.
	•	Max/min density \rho_{\max/\min}: excess of maximal or minimal elements → timelike.
	•	Null sheet test: high link fraction f_L = L/R with suppressed long [[Chains]] and strong anisotropy of link directions.
	•	Local dimension & curvature (Myrheim–Meyer dim, Benincasa–Dowker action) jump across boundaries.

[[Physics]] meaning
	•	Boundaries cap [[Domains]] of dependence; null sheets act like horizons (one-way information flow).
	•	Areas/lengths are estimated by counting elements in the [[New Readers Start Here/I - Pleroma Archive/World/Locations/Oneiroverse Multiverse/Chorus of Archetypes/Boundary]] layer; fluxes by link counts that pierce the surface.
	•	Entropy bounds/holographic behavior can be phrased as element counts on 𝓝.
